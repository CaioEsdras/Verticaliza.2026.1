🚀 Projeto de Estudos — HTML, CSS e JavaScript

Este repositório foi criado como parte do meu processo de aprendizado em desenvolvimento web, utilizando HTML, CSS e JavaScript.

O objetivo é praticar conceitos básicos da web por meio de exercícios, páginas simples e pequenos projetos, evoluindo gradualmente conforme avanço nos estudos.

🎯 Objetivo

Aprender os fundamentos do desenvolvimento web

Praticar a criação de páginas com HTML

Aplicar estilos com CSS

Desenvolver lógica básica e interatividade com JavaScript

Entender a organização de arquivos e versionamento com Git/GitHub

🛠️ Tecnologias Utilizadas

HTML5 — estrutura das páginas

CSS3 — estilização e layout

JavaScript — lógica e interatividade

📚 Conteúdos em Aprendizado

Manipulação simples do DOM

Boas práticas iniciais de organização de código
